# Les bonnes pratiques

!!! info "À construire"

Les bonnes pratiques suivantes portent sur l'**écriture du code** :

* [Les conventions de nommage et de codage](conventions.md)
* Le formatage automatique et l'analyse statique du code (formateurs, *linters*)
* Les commentaires et la documentation du code
* Les tests unitaires (principe illustré avec une fonction `somme(a, b)` et son test `testSomme()`)

Voir aussi, dans la rubrique [Architecture](../../architecture/index.md), les principes de conception (SOLID, KISS...) abordés dans le cours [Les patrons de conception](https://mborne.github.io/cours-patron-conception/) et [le refactoring](../../architecture/refactoring/index.md).
