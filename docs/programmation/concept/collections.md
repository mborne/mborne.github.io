# Les collections

Le concept de **collection** permet de faire abstraction sur une **structure de données permettant de représenter en ensemble d'éléments**.

## En pratique

* PHP définit une interface [Iterable](https://www.w3schools.com/php/php_iterables.asp) unifiant les types pouvant être parcours à l'aide de `foreach`.
* JavaScript procède de même (voir [fr.javascript.info - Iterables](https://fr.javascript.info/iterable))
