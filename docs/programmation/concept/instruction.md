# Les instructions

Une instruction est **un ordre** donné à une machine par le biais d'un programme.

## En pratique

* Les instructions les plus primitives sont en langage machine (binaire)
* Les langages assembleurs amènent [des instructions élémentaires](https://web.maths.unsw.edu.au/~lafaye/CCM/asm/liste.htm) très proches de ce langage machine.
* Les langages de plus haut niveau amènent des abstractions qui sont finalement traduites par un compilateur ou un interpréteur en langage machine.
