# La gestion des erreurs

!!! info "À construire"

    Les fiches de cette rubrique restent à rédiger.

La gestion des erreurs prend des formes différentes selon les langages et les paradigmes :

* Les codes de retour
* Les exceptions
* Les types Result et Option
* Les erreurs irrécupérables (panic, assertions)
* La libération des ressources (`defer` en Go, `finally`, RAII en C++, `with` en Python, *try-with-resources* en Java...)
* Les bonnes pratiques
