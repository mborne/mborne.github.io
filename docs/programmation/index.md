# La programmation

Cette rubrique, **en construction**, regroupe des concepts de programmation, notamment pour traiter des prérequis du cours [Les patrons de conception](https://mborne.github.io/cours-patron-conception/) :

* [Les concepts de base](base/index.md) : instructions, variables, types, opérateurs, boucles, fonctions...
* [Les variables et la mémoire](memoire/index.md) : pile, tas, pointeurs et ramasse-miettes.
* [La programmation orientée objet](poo/index.md) : classes, encapsulation, héritage, interfaces...
* [La programmation générique](generique/index.md) : génération de code (C++, Rust) et restriction de type (Java, TypeScript...).
* [Les structures de données](structures-de-donnees/index.md) : collections, arbres, index spatiaux, graphes...
* [La programmation fonctionnelle](fonctionnelle/index.md) : générateurs, lambdas, map / filter / reduce...
* [La gestion des erreurs](erreurs/index.md) : codes de retour, exceptions, types Result et Option...
* [Système et interfaçage](systeme/index.md) : concepts des systèmes d'exploitation, bibliothèques et interfaçage entre langages.
* [Les bonnes pratiques](bonnes-pratiques/index.md) : conventions, formatage, documentation et tests du code.
