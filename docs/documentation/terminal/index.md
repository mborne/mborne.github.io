# Enregistrement du terminal

Pour illustrer une documentation avec des commandes et leurs résultats, il est possible d'**enregistrer une session de terminal** plutôt que de réaliser des captures d'écran :

- [asciinema](../../outils/asciinema/README.md) enregistre une session de terminal sous forme de texte (fichier `.cast`) et permet de la **rejouer dans une page web**.
