# Les diaporamas

Il est aussi possible de **générer des diaporamas en HTML** à partir de Markdown.

## Outils

- [Marp (Markdown Presentation Ecosystem)](https://marp.app/#get-started)
- [reveal.js](https://revealjs.com/)
- [remark](https://remarkjs.com/)

## Exemples

Les supports de mes cours à Géodata Paris sont rédigés en Markdown et publiés avec GitHub Pages :

- [cours-devops](https://mborne.github.io/cours-devops/) ([sources](https://github.com/mborne/cours-devops)) : Introduction à la méthode DevOps (Marp)
- [cours-archi-si-geo](https://mborne.github.io/cours-archi-si-geo/) ([sources](https://github.com/mborne/cours-archi-si-geo)) : Introduction à l'architecture des SI avec un focus sur la gestion des données spatiales (Marp)
- [cours-patron-conception](https://mborne.github.io/cours-patron-conception/) ([sources](https://github.com/mborne/cours-patron-conception)) : Principes et patrons de conception (remark)
