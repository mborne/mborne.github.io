# Les dépôts

## Principaux dépôts

* [github.com - mborne/cours-patron-conception](https://github.com/mborne/cours-patron-conception#les-patrons-de-conception) : dépôt contenant la source markdown de la présentation
* [github.com - mborne/tp-geometry-ts](https://github.com/mborne/tp-geometry-ts) : dépôt contenant un projet NodeJS pour débuter le [TP - Patrons de conception avec des classes géométriques](../tp-geometry-ts/index.md)
* [github.com - mborne/tp-graph-ts](https://github.com/mborne/tp-graph-ts) : dépôt contenant un projet NodeJS pour débuter le [TP - Refactoring de traitement de graphe](../../refactoring/tp-graph-ts/index.md)

## Anciens dépôts

Les dépôts suivants ne sont plus utilisés depuis le remplacement de Java par TypeScript :

* [github.com - mborne/tp-geometry-java](https://github.com/mborne/tp-geometry-java) : dépôt contenant un projet Maven pour débuter le TP - Patrons de conception avec des classes géométriques en Java.
* [github.com - mborne/tp-graph-java](https://github.com/mborne/tp-graph-java) : dépôt contenant un projet Maven / [Spring-Boot](https://spring.io/projects/spring-boot) pour débuter le TP - Refactoring de traitement de graphe en Java.
